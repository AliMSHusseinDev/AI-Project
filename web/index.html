How it works

GA keeps a population of layouts. It selects better layouts, combines them, and changes sensor locations. MA adds a small local search: it moves sensors towards holes or the connected network, then checks if a redundant sensor can be removed.

A result is feasible only when coverage and connectivity are both 100%. The base station sends data but does not sense. Touching an obstacle blocks a signal. These methods search for a small sensor count; they do not prove the global minimum.
